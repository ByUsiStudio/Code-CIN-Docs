# CIN 初学者教程

这是一套从零开始的 CIN 编程教程。不需要任何编程经验, 只要会基本的电脑操作
(创建文件、打开终端、敲命令) 就能跟下来。如果你已经会 C / Go / Python, 也可以把它当
“CIN 快速上手指南”阅读。

::: tip 三条学习路径
- **完全零基础**: 从 [第 1 章](/beginner/ch01-hello) 顺序读到
  [第 13 章](/beginner/projects), 动手敲每一段代码。
- **会别的语言**: 先读 [第 1 章](/beginner/ch01-hello) 与
  [速查表](/beginner/cheatsheet), 再跳到 [与 C/Go 的差异](#与-cgo-最容易踩的五个差异)。
- **只想查语法**: 直接看 [速查表](/beginner/cheatsheet), 或去
  [CIN 语言总览](/language/) 查细节参考。
:::

## 学完你能做什么

读完并完成练习后, 你能够:

- 写出、运行、调试多函数的 CIN 程序 (变量、分支、循环、函数、数组、字符串、struct);
- 使用 36 个内置标准库 (排序、统计、字符串处理、随机、JSON…);
- 用 `import` 把自己的代码拆成多个文件;
- 读懂编译器/运行时的错误面板并自己定位问题;
- 用 `--json` 拿到机器可读的运行结果, 方便脚本与判题;
- 用文件、网络、画布、系统交互等宿主能力写出真正有用的小工具;
- 把程序编译成不需要 Python 的独立可执行文件 (`--build-exe`)。

## 准备环境 (只做一次)

你需要:

1. **Python 3.8 或更高版本** — CIN 的命令行外壳由 Python 提供;
2. **Code CIN 本体** — 一条命令安装:

```bash
pip install codecin
codecin --version        # 打印当前版本
```

想拿到最快的执行速度, 再装一个 Go 工具链 (安装时会自动编译原生加速库);
没有 Go 也能正常学习和运行, 只是速度慢一些。完整说明见
[安装 Code CIN](/guide/installation)。

3. **一个能写代码的编辑器** — VS Code、Notepad++、Vim 都行;
   仓库 `misc/vim/` 还提供 Vim 语法高亮。

## 与 C/Go 最容易踩的五个差异

先记住这五条, 能省下大量调试时间:

| 差异 | CIN 的行为 | 你该怎么做 |
|------|-----------|-----------|
| 除法 | `/` **永远是浮点除法**, `7 / 2` 得到 `3.5` | 要整数商用 `idiv(7, 2)` (= `3`) |
| 语句结尾 | 语句以**换行**结尾, 分号可选; 块内换行不能省 | 一行一条语句, 别把两条挤在一行 |
| 字符串比较 | `==` 比的是**指针**, 不是内容 | 用 `strcmp(a, b) == 0` |
| 指针 | 没有取地址/解引用; 数组与 struct 传参天然是引用 | 需要“传出”多个值时, 传入一个结果数组 |
| 数组长度 | 数组**不携带长度** | 所有数组函数都显式传 `n` (元素个数) |
